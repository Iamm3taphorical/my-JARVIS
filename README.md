# JARVIS

Local voice assistant with a web screen.

## Setup

```bash
chmod +x setup.sh
./setup.sh
```

## Run Voice Mode

```bash
source venv/bin/activate
python main.py
```

## Run With GUI

```bash
source venv/bin/activate
python main.py --gui
```

Open this in your browser:

```text
http://127.0.0.1:8765
```

## Useful Commands

```text
open youtube
open vs code
what is the weather
search the web for Python tutorials
play lofi music on youtube
open config json in vs code
open word editor and write buy milk
```
